# XiaoVPN
Xiao VPN

A modern cross-platform VPN project for Android and Windows.

Xiao VPN is an open-source project focused on building a clean, convenient and secure VPN experience with a unified design across mobile and desktop platforms.

«🚧 Project status: Early development. Xiao VPN is currently under development. Not all planned features are implemented yet.»

✨ Features

- 📱 Android app — built with Kotlin and Jetpack Compose.
- 🖥️ Windows app — planned with C# and WinUI 3.
- 🔐 VPN protocols — planned support for WireGuard and AmneziaWG.
- 📂 Configuration import — import supported VPN configurations.
- 🌐 Server management — planned server list and management system.
- 🎨 Unified interface — modern blue-and-white visual design.

🧩 Project Structure

Directory| Description
"android/"| Android application
"windows/"| Windows application
"shared/"| Shared models and API definitions
"engines/"| VPN engine integrations
"server/"| Backend and server management
"docs/"| Documentation
".github/"| Build workflows

🛠️ Technology Stack

🔒 Security

Security is a core development priority.

- Use established VPN implementations.
- Never commit private keys, passwords or access tokens.
- Clearly document data collection and privacy practices.
- Keep third-party licenses and notices.
